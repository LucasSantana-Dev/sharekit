## Phase 1 — High

1. [security/high/m] Executable dotfiles bypass hook gate → silent RCE
   - Evidence: src/plan.ts:61 — gate is `!includeHooks && f.tool === 'claude' && basename === 'settings.json'`; profile shipping `shared/.zshrc` (or `.bashrc`, `.zprofile`, `.profile`, `.bash_profile`) lands in `~/` after generic confirm → executes on next shell
   - Fix: extend gating to a denylist of executable-on-load dotfiles in shared/ (flag in preview, skip by default, `--include-dotfiles`-style opt-in or per-file confirm). Consider cursor/opencode config with executable semantics too.

2. [correctness/high/s] Version triple-drift: package.json / src/index.ts:27 VERSION / sharekit-pip/pyproject.toml
   - Fix: single source (read package.json at build or bump script updating all three atomically); pairs with #3.

3. [ci/high/xs] release.yml never validates tag == manifest versions before publishing
   - Evidence: release.yml:119 `VERSION="${GITHUB_REF_NAME#v}"` used for brew/binaries; npm/PyPI publish whatever's in manifests → tag v0.6.0 + stale manifests = split-brain release
   - Fix: first job asserts `jq -r .version package.json == $VERSION` and pyproject version == $VERSION; fail fast.
